# 🏋️ FitLog — Workout Library
A dark, no-nonsense gym companion built with Next.js. Browse a library of workouts, dive into detailed instructions, and build your daily training plan — all in one place.

## 🛠️ Technologies Used
- Next.js
- TypeScript
- Tailwind CSS 
- daisyUI
- react-toastify for notifications


### ✨ Features
1. Workout Library — Browse 12 workouts in a responsive grid, each with category tags, equipment, duration, calories, and rating.
2. Workout Detail Pages — Dynamic routes with full instructions, key specs, and category tags for every lift.
3. Today's Plan & Saved Tabs — Add workouts to a daily plan or save them for later, with live badge counters in the navbar.
4. Sort & Filter — Sort the workout library by duration, calories, or rating.
5. Toast Notifications — Instant feedback for every action: adding, saving, removing, and marking workouts done.
